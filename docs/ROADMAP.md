# Novel Studio - 开发路线图

本文档规划项目的版本迭代计划和里程碑目标。

---

## 当前版本：v0.1 (基础功能完成)

### ✅ 已完成
- Bible 创建与结构化存储
- Substory 生成引擎
- Chapter Blueprint 生成
- Scene 节拍规划
- Writing Engine 核心实现（基于场景节拍的正文生成）
- Material Provider 抽象层

---

## v0.2 - 质量与稳定性提升 (计划中)

**目标**：完善现有功能，提升系统稳定性和用户体验。

### 核心任务

#### 1. Post-Writing 模块 (优先级：🔴 高)
- [ ] 实现 `chapter_summary` 功能
- [ ] 设计并实现 `cumulative_substory_summary` 更新策略
- [ ] 提取关键事件并结构化存储
- [ ] 集成到 Writing Pipeline

**预计工时**：1-2 周  
**依赖**：需要先设计好 Summary 的存储结构

---

#### 2. 流式传输支持 (优先级：🟡 中高)
- [ ] 修改 `chain.py`，支持 Streaming 模式
- [ ] 重构 `WritingEngine.scene_writing` 为异步生成器
- [ ] 前端/API 层适配（SSE 或 WebSocket）
- [ ] 性能测试与优化

**预计工时**：1 周  
**依赖**：前端需要同步支持流式接收

---

#### 3. 测试体系建设 (优先级：🟡 中高)
- [ ] 为核心模块添加单元测试（目标覆盖率 60%+）
  - `writing` 模块
  - `outlines` 模块
  - `materials` 模块
- [ ] 设计并实现 Mock LLM 策略
- [ ] 编写 BDD 测试用例（至少覆盖 2 个完整流程）
- [ ] 集成 CI/CD（GitHub Actions）

**预计工时**：2 周  
**依赖**：需要明确测试策略和工具选型

---

### 次要任务

#### 4. 错误处理与重试机制
- [ ] LLM 调用失败时的自动重试
- [ ] 记录异常日志并通知用户
- [ ] Token 超限时的优雅降级（如自动截断上下文）

**预计工时**：3-5 天

---

#### 5. Service 层开发 (优先级：🔴 高)
- [ ] 设计 RESTful API 接口规范
- [ ] 实现核心 Service 层（Bible、Substory、Writing 等模块的 API 封装）
- [ ] 添加请求验证和错误处理
- [ ] 集成流式传输到 API 层（SSE/WebSocket）
- [ ] 编写 API 文档（OpenAPI/Swagger）

**预计工时**：1-2 周  
**依赖**：Post-Writing 模块和流式传输完成后集成

---

#### 6. 前端初版 (MVP) (优先级：🟡 中高)
- [ ] 选型确定（建议 Next.js/React + TailwindCSS）
- [ ] 实现核心页面
  - Bible 创建与编辑
  - Substory 查看与管理
  - Chapter 创作界面（支持实时流式显示）
- [ ] 基础交互与状态管理
- [ ] 与 Service 层对接

**预计工时**：2-3 周  
**注**：初版聚焦在功能可用性，UI/UX 精细化留待后续版本

---

#### 7. 文档完善
- [ ] 补充 API 文档
- [ ] 编写用户使用手册
- [ ] 记录架构设计文档

**预计工时**：1 周

---

## v0.3 - 评估与优化 (远期规划)

**目标**：建立质量评估体系，实现持续优化能力。

### 核心任务

#### 1. 评估模块 (Evaluation Module)
- [ ] 实现 LLM-as-a-Judge 评估器
- [ ] 定义评估指标体系（情节、人物、文笔、情感）
- [ ] 建立评估数据存储（关联 Prompt 版本和生成结果）
- [ ] 可视化质量趋势

**预计工时**：2-3 周

---

#### 2. Prompt 优化工具链
- [ ] Prompt 版本管理系统
- [ ] A/B Testing 框架
- [ ] 自动化 Prompt 调优（探索 DSPy 等工具）

**预计工时**：2 周

---

#### 3. 高级后处理功能
- [ ] 人物状态追踪
- [ ] 冲突/悬念管理
- [ ] 自动质量检测与修正建议

**预计工时**：1-2 周

---

## v0.4 - 用户体验优化 (中期规划)

**目标**：提升前端体验，打磨细节，构建完整产品形态。

### 核心任务

#### 1. 前端精细版 (优先级：🟡 中)
- [ ] UI/UX 重构与美化
  - 统一设计系统（颜色、字体、组件库）
  - 动画与过渡效果
  - 响应式布局优化
- [ ] 高级交互功能
  - 拖拽式章节排序
  - 富文本编辑器（支持 Markdown）
  - 历史版本对比与回滚
- [ ] 性能优化
  - 虚拟滚动（处理长文档）
  - 懒加载与代码分割
  - 缓存策略

**预计工时**：3-4 周

---

#### 2. Service 层增强
- [ ] API 性能优化（缓存、批量处理）
- [ ] 用户认证与权限管理
- [ ] 多项目/多用户支持

**预计工时**：1-2 周

---

## v0.5+ - 未来愿景 (探索阶段)

### 可能方向
- **世界观编辑器**：可视化管理设定，自动检测矛盾
- **多版本生成**：关键章节生成多个候选，用户筛选
- **插件化架构**：支持自定义 Prompt、评估规则、后处理逻辑
- **跨语言支持**：扩展至英文等其他语言的小说创作
- **多模态集成**：配图建议、语音输入、AI 配音等
- **协作功能**：多人共同创作、评论与批注
